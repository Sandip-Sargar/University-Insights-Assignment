# University-Insights-Assignment

Project: Study MBBS Abroad - Responsive Landing Page

This project is a responsive landing page** designed for students interested in studying MBBS abroad. It provides key details about the benefits, top countries, and the admission process. The page includes a lead generation form to collect user details for further communication.

✅ Hero Section – Eye-catching banner with CTA (Apply Now)
✅ Why Study MBBS Abroad? – Highlights key benefits
✅ Top Countries– Lists popular MBBS destinations
✅ Admission Process – Step-by-step guide
✅ Lead Form– Collects user details
✅ SEO Optimize– Metadata, structured content, and fast loading
✅ Google Analytics & Facebook Pixel – For performance tracking

Tech Stack:

Frontend: HTML, CSS (Tailwind), JavaScript
Form Validation: JavaScript
Deployment: Netlify/Vercel
This project ensures a mobile-friendly and fast-loading experience, making it easy for students to explore MBBS opportunities abroad. 🚀
